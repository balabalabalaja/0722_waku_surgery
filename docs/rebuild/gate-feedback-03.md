## conductor 排查方向（供参考，以实测为准）

（对第 2 条）嘴环位于人正下方、整环被身体遮挡——大盘构图（A）下
竖屏近景几乎必然全遮。修法方向：嘴环位置/半径调整，让它像 ref-03
那样从人身侧探出月牙（如移向左下/右下侧、抬高圆心或加大半径出画），
保证竖屏近景至少稳定露出一段可拨的弧；不得违背"环在人身后"层序。

- 窗口画境层是否按 devicePixelRatio 全分辨率渲染（canvas 内部
  分辨率 = CSS 尺寸 × DPR，Retina 下 DPR 2-3；若按 CSS 像素画，
  上脸即糊而环上小尺寸绘制不显）；
- 素材是否存在"先缩小再放大"的两段链路（如先合成到低分辨率
  离屏层再放大贴窗）；
- 取景倍率 1.35 + 窗口 0.80 下的实际放大倍数 vs 素材原始分辨率
  （眼 341×149 / 嘴 430×188 / 鼻 310×540）——若修完渲染链路仍因
  源分辨率不足而软，明确写进 fix-03-done：conductor 将请玩家从
  Illustrator 按 4x 重导素材（当前为 2x）。
- imageSmoothing 设置与背景模糊层是否波及窗口内容。
