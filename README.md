# SURGERY — art-history face collage

Live-camera playable: three glass dials of masterpiece eyes, noses and
mouths orbit your head — spin them (touch-drag or palm-swipe on camera) to
remix your face, pinch the white brackets to size each part, then snap a
polaroid card with the painting credits.

## Run

```bash
npm install
npm run dev      # http://localhost:8891 (portrait viewport)
npm test         # state machine / geometry / content tests
npm run lint     # tsc --noEmit
npm run build    # production bundle → dist/
```
